# 投诉处理 - 标准操作流程

## 1. 道歉与安抚
- 立即道歉，表达重视
- 安抚客户情绪
- 承诺会认真处理

## 2. 了解事实
- 耐心听客户描述
- 记录关键信息（时间、订单号、问题详情）
- 确认投诉焦点

## 3. 核实情况
- 查询订单/服务记录
- 核实投诉事实
- 确定责任归属

## 4. 提出方案
- 根据投诉等级提供解决方案
- 说明处理流程和时限
- 征求客户意见

## 5. 执行处理
- 创建投诉工单
- 发起补偿流程（如适用）
- 按权限审批或升级

## 6. 跟进闭环
- 处理后回访客户
- 确认满意度
- 记录经验教训

## 升级条件
- 金额超过500元 → 主管审批
- 涉及法律/媒体 → 立即升级
- 客户强烈不满且安抚无效 → 转高级客服
