# 退换货处理 - 标准操作流程

## 1. 安抚与确认
- 致歉并安抚
- 确认退货/换货/退款原因

## 2. 资格判断
- 查询订单信息（购买时间、商品类型）
- 判断是否符合退换货条件
- 不符合条件时说明原因和替代方案

## 3. 方案提供
- 退货：发送退货地址 + 流程说明
- 换货：确认换货规格 + 有货否
- 退款：说明退款金额和时效

## 4. 运费说明
- 明确告知运费承担方
- 提醒勿寄到付件

## 5. 凭证要求
- 提醒拍照留存
- 告知包裹内放纸条（订单号+原因）
- 告知寄回后需提供快递单号

## 6. 跟进记录
- 创建退换货记录
- 告知后续验收和退款节点
- 承诺跟进

## 升级条件
- 超过退货期限但客户强烈要求 → 升级处理
- 退款金额有争议 → 主管审核
- 批量退货/大额订单 → 财务审核
