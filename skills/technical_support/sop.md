# 技术支持 - 标准操作流程

## 1. 问题确认
- 了解问题现象和影响范围
- 确认问题首次出现时间
- 询问最近是否有变更（更新、配置修改等）

## 2. 环境收集
- 记录操作系统和版本
- 记录浏览器/App版本
- 请求错误截图或录屏

## 3. 逐步排查
- 从最简单的方案开始引导
- 每步操作后等待客户反馈
- 排除法定位问题

## 4. 解决方案
- 找到原因后提供解决步骤
- 确认问题是否彻底解决
- 告知预防措施

## 5. 升级处理
- 无法远程解决 → 创建技术工单
- 紧急问题（宕机/数据/安全）→ 立即升级
- 告知处理流程和预计时间

## 6. 跟进闭环
- 记录排查过程
- 工单转交技术团队
- 跟进处理进度并反馈客户

## 升级条件
- 影响生产环境 → 紧急工单（响应<30分钟）
- 数据丢失/损坏 → 最高优先级
- 安全漏洞 → 立即上报安全团队
- 无法在30分钟内解决 → 创建工单
