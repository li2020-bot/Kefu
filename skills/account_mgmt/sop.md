# 账户管理 - 标准操作流程

## 1. 身份验证
- 确认注册手机号或邮箱
- 验证客户身份（至少2项信息）
- 高风险操作需额外验证

## 2. 问题分类
- 登录问题：引导重置密码或排查验证码
- 认证问题：核实信息一致性
- 安全问题：立即标记优先级

## 3. 解决方案
- 密码类：引导自助重置流程
- 认证类：线上可处理的即时处理，否则提交人工审核
- 安全类：冻结账号 → 修改密码 → 核实异常操作 → 恢复

## 4. 操作执行
- 记录操作类型和原因
- 客户确认后执行
- 发送操作结果通知（短信/邮件）

## 5. 安全提示
- 建议开启双重验证
- 提醒定期修改密码
- 注意防范钓鱼链接

## 升级条件
- 账号被盗/盗刷 → 立即冻结+升级安全团队
- 大额异常交易 → 升级风控团队
- 批量账号异常 → 升级安全+运维
- 客户威胁报警/法律手段 → 升级法务
